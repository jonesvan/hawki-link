Hawki Link

Autonomous web agent settings

Agent engine

A chat model can reason and call tools. Jev is a non-generative decision model: every step is a typed Choice/Score/Noul decision made in code, so it cannot write free text or arbitrary code.

DeepSeek

Stored locally in this browser only (chrome.storage.local). Never sent anywhere except your configured API endpoint.

Jev (TypeSafe System One)

Below this confidence the agent re-reads the page instead of acting. Jev is served by OpenRouter at https://openrouter.ai/api/v1/systemone. Defapi does not expose the System One route.

Agent behaviour

Trusted input attaches Chrome's debugger to send real mouse/keyboard events (needed by canvas apps, file uploads, and sites that check isTrusted). It shows a "debugging this browser" bar and unlocks network/emulation tools.

Page dialogs & print

Native alert, confirm, prompt and window.print() block the page and cannot be seen from a content script. Hawki Link intercepts them in the page so the agent never hangs.

Security notes

  • The agent can read page content and interact with sites you are logged into. Only run tasks you trust.
  • It will ask before spending money, sending messages, or deleting data.
  • Passwords you provide via the agent are typed into the page and are not stored by Hawki Link.
